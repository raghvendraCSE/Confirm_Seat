# 🏠 ConfirmSeat

### Find a place that feels like home.

**ConfirmSeat** is a responsive rental accommodation website designed to help students and working professionals explore rooms, PGs, and flats near their colleges or workplaces.

Our goal is to make rental searching simpler through useful property details, budget filters, and easy communication.

## 🌟 Features

- 🔍 **Property Search** – Search rental options by location or property name.
- 🏘️ **Property Categories** – Explore PGs, rooms, and flats.
- 💰 **Budget Filters** – Filter properties according to monthly rent.
- ❤️ **Save Favourites** – Save preferred properties using Local Storage.
- 📱 **Responsive Design** – Compatible with desktop, tablet, and mobile devices.
- 📧 **Contact Form** – Prepare enquiries directly through email.
- ❓ **FAQ Section** – Find answers to common questions.
- ☰ **Mobile Navigation** – Easy navigation on smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

No installation or additional dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/raghvendracse/ConfirmSeat.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
